# Habit-tracker App
A daily habit grid. Users add habits they want to build, tick each one off daily, and see a weekly view of their progress.

## Stack
- Plain HTML, CSS, JavaScript(no framework)
- Data stored in 'localStorage'
- No build step — open `index.html` directly in a browser
- The site will be hosted on GitHub Pages.

## Running the app
Open `index.html` in Chrome. No server needed.

## Conventions
- One file per concern: `index.html`, `style.css`, `app.js`
- Don't add any external libraries or packages without asking me first
- Don't add any new pages — everything stays on one screen
- Show 'undo' button for 5 seconds until time expires.
- If anything is unclear, ask me a question before making assumptions.
- Always confirm with me before adding a new feature or page that wasn't in the original request


## Do not
- Add any npm dependencies
- Commit any secrets — no API keys, passwords, or tokens in the files
